# Verdensbiblioteket – seks bøker, seks biblioteker

En liten selvstendig, interaktiv bokreise på norsk.

Åpne [index.html](./index.html) i nettleseren. Bla mellom seks biblioteker, velg bøker med avkryssing og kopier leselisten. Ingen bygging, biblioteker eller konto kreves.

## Presisjonsgrenser

Dette er en **kurert leseliste**, ikke en bekreftet oversikt over eksakte beholdninger eller tilgjengelige lån. Enkelte verk er historiske originaler som ikke kan hjemlånes. Andre er tematiske forslag, uten verifisert katalogpost. Ingen lån er gjennomført. Bøker er ikke digitalisert eller gjengitt; opphavsrettslig beskyttede fotografier og omslag er ikke inkludert.

## Videre arbeid

Verifiser katalogpost, faktisk tilgjengelighet, utlånsrett og eventuelle digitale leseutgaver hos hvert bibliotek før det legges til direkte lenker eller status som «tilgjengelig».
